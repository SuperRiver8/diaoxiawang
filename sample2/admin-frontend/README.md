# 釣蝦王管理端・方案二

Vite + React + TypeScript 純前端管理演示，採用深紫控制台、窄圖標控制列與亮橙操作票籤，預設端口 3003。

```bash
npm install
npm run dev
```

演示管理員：`admin@demo.hk / admin1234`

可用命令：`npm run lint`、`npm run typecheck`、`npm test`、`npm run test:e2e`、`npm run build`。生產靜態檔案輸出至 `dist/`。

此專案不連接 API；管理操作只保存在本機 `shrimp-admin-demo-v2`，上傳與郵件均為模擬功能。
