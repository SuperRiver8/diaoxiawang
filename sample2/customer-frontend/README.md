# 釣蝦王顧客端・方案二

Vite + React + TypeScript 純前端演示，採用深紫與亮橙「霓虹潮玩票券」設計，預設端口 3002。

```bash
npm install
npm run dev
```

演示會員：`member@demo.hk / demo1234`

可用命令：`npm run lint`、`npm run typecheck`、`npm test`、`npm run test:e2e`、`npm run build`。生產靜態檔案輸出至 `dist/`。

此專案不連接 API；註冊、登入及會員狀態只保存在本機 `shrimp-customer-demo-v2`。
